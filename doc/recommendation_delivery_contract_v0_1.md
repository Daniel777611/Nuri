# NURI 推荐交付契约 v0.1

- 记录日期：2026-08-03
- 状态：产品已确认；作为 `daniel-test` 推荐链路的实现与验收基线
- 依赖基线：`doc/content_source_whitelist_v0_9.md`

## 1. 产品承诺

NURI 不向用户展示一堆搜索结果，而是：

> 围绕刚刚聊到的一个具体问题，结合孩子当前发展阶段和家庭真实限制，提前完成搜索、判断、核验和筛选，交付一条可信判断、一个立即可做的方法和一个相似家庭的真实参考。

白名单只回答“哪些来源可以进入候选池”。本契约回答“具体什么内容可以出现在用户面前”。

## 2. 推荐单元：一个问题，一个内容包

每次首页展示一个完整的 `Recommendation Set`。内容包只能围绕一个具体问题，不能把一次长对话中的多个问题混在一起。

结构化输入至少包括：

- `primary_topic`：当前主要话题。
- `user_job`：用户此刻真正想解决的问题。
- `child_age_months`：根据生日实时计算的月龄。
- `development_stage`：对应发展阶段。
- `parent_constraint`：时间、工作、家庭结构等真实限制。
- `content_language`：文字语言。
- `audio_language`：普通话、粤语、英语等。
- `preferred_format`：短视频、短文章、长文等。
- `risk_level`：普通育儿、需要专业评估、临床高风险。
- `recently_seen_ids`：最近曝光、点击、收藏、更换或拒绝的内容。

最新对话的明确意图必须高于旧对话主题。主题判断信心不足时保留上一组推荐，不勉强猜测。

## 3. 首页固定三张卡片

三张卡片围绕同一个问题，但必须回答三个不同问题。

### 3.1 权威答案

回答：这个发展阶段通常是什么情况、值得观察什么、什么时候需要进一步咨询？

- 主内容来自政府、专业医学会、大学、医院或权威研究机构。
- 标题必须针对当前家庭语境，不能只复制来源原标题。
- 详情包含一篇权威文章和一个权威讲解视频。
- 对里程碑、筛查和医疗边界给出明确提醒。

### 3.2 精选方法

回答：用户今天具体可以怎么做？

- 优先选择小红书、YouTube、B站、优秀育儿博主及高可读性专业平台。
- 主内容可以是博主短视频或易读文章，但核心结论必须绑定 A/B 级权威证据锚点。
- 详情包含一个最值得看的视频和一篇补充文章。
- 内容应具体、可执行，并匹配用户的时间和家庭限制。

### 3.3 相似案例

回答：情况相近的家庭实际经历了什么、怎么坚持、遇到什么问题？

- 主要来自真实家庭记录、公益机构案例、医院匿名家庭故事或审核后的创作者内容。
- 详情包含一个案例文章和一个案例视频。
- 必须标注“单个家庭经验，不代表普遍效果或医学建议”。

## 4. 首页卡片必须展示的信息

- 明确类别：权威答案 / 精选方法 / 相似案例。
- 不同的收益型标题，不能三张卡只换来源和颜色。
- 一句“为什么推荐给你”。
- 来源机构或创作者名称。
- 文字语言和视频音轨语言。
- 预计阅读和观看时间。
- 适用月龄或发展阶段。
- “内容已准备好”的可点击状态。

示例主题：9 个月宝宝语言发展，父亲创业忙、陪伴时间少。

- 权威答案：`9个月宝宝的咿呀与回应：哪些是正常进展`
- 精选方法：`忙碌爸爸也能做：每天5分钟的轮流对话`
- 相似案例：`一位创业爸爸如何把换尿布变成语言互动`

## 5. 详情页：学习胶囊，而不是搜索页

用户点击首页卡片时，必须直接打开已经准备完成的结果。详情页包含：

1. 80–150 字 NURI 导读。
2. 为什么这组内容适合当前用户。
3. 一篇主要文章。
4. 一个主要视频。
5. 1–3 个今天可以执行的小行动。
6. 来源、作者、可信度、语言和更新时间说明。
7. 反馈：有帮助、不相关、太长、看过了、语言不对、广告太多、换一个。

详情页不显示长来源目录，不允许点击后才开始实时搜索。

## 6. 准备和发布生命周期

```text
结束一次有实质内容的对话
→ 提取结构化需求
→ 三个类别分别召回候选
→ 完成语言、月龄、链接、广告和证据校验
→ 为三张卡准备文章、视频与详情页
→ 三张全部 ready
→ 原子替换首页旧内容包
```

- 准备过程中旧内容包继续可看、可点击。
- 禁止用加载遮罩阻断首页。
- 三张未全部完成时，不替换旧包。
- MVP 每类预先保存至少一个备用组合；备用不足时保留当前可用组合并在后台补充。
- “换一个”立即切换到备用组合，候选不足时再在后台补充。

## 7. 候选准入硬门槛

任何一项不满足就不得推送：

- 与孩子月龄和发展阶段匹配。
- 与当前用户问题和目标匹配。
- 文字、音轨和字幕语言真实匹配。
- 链接可访问，视频不是广告、预告片或残缺片段。
- 无未披露带货、赞助、付费课程、问诊或医疗导流。
- 医疗高风险内容来自高等级来源并经过更严格审核。
- 精选内容的关键观点存在权威证据锚点。
- 案例不冒充普遍结论。
- 最近没有给该用户重复推荐。
- 不是同一机构或同一内容的不同包装。

## 8. 排序原则

### 8.1 权威答案

- 对话意图匹配：30%
- 月龄/阶段匹配：20%
- 证据与来源质量：20%
- 语言匹配：10%
- 家庭限制匹配：10%
- 可理解、可执行性：10%

### 8.2 精选方法

- 对话意图匹配：30%
- 月龄/阶段匹配：15%
- 与权威证据一致：15%
- 可读性和表达质量：15%
- 收藏、有效评论和观看质量：10%
- 用户格式偏好：10%
- 新鲜度：5%

### 8.3 相似案例

- 对话意图匹配：25%
- 家庭处境相似度：20%
- 月龄/阶段匹配：15%
- 案例真实性：15%
- 不违背权威证据：10%
- 用户偏好：10%
- 新鲜度：5%

浏览量、点赞量和粉丝量只作为弱信号。收藏、有效评论、观看完成度和用户后续实际反馈权重更高。

## 9. 多样性和个性化

- 每组三张卡各有一个类别。
- 三张卡必须有不同标题和不同用户收益。
- 三张卡默认来自三个不同 `parent_org_id`。
- 同一内容的转载、剪辑和不同语言版本只算一条。
- 问卷偏好决定首页默认先展示哪一张，不删除其他类别。
- 点击、停留、完成、收藏、分享、更换和负反馈调整未来排序。
- 保留 10%–20% 探索流量，避免长期只推荐同一种内容。

## 10. MVP 验收标准

- 用户结束对话返回首页后，无需刷新即可看到与最新话题匹配的新内容包。
- 首页三张卡标题和作用明显不同。
- 每张卡点击后立即看到一篇文章和一个视频。
- 详情页不出现“正在搜索”或空结果。
- 简体中文用户默认不会收到粤语视频。
- 一个内容包中同一机构最多出现一次。
- “换一个”在 300ms 内切换已准备的备用组合。
- 用户明确拒绝的 URL、来源、语言和重复主题进入冷却期。
