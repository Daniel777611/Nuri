# Nuri iOS release feed

This dedicated data branch publishes minimal public version metadata for the existing Nuri Alpha and Beta TestFlight channels. Do not merge this data-only tree into application or backend source branches.

Only announce a build after App Store Connect confirms it is VALID, IN_BETA_TESTING, unexpired and actually attached to its existing public test group. Preserve the existing TestFlight links and 30-person limits. Record Apple's minimum OS version and exact expiration date. Never publish credentials, review logins, customer data or application source in this feed.

Beta and Pro keep Community disabled until Daniel explicitly authorizes opening it. Pro checks its actual App Store storefront and does not use this TestFlight feed.
